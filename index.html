Firebase verbinden

In der Firebase-Konsole: Zahnrad → Projekteinstellungen → Allgemein → «Deine Apps» → deine Web-App → «Konfiguration». Den ganzen Block mit const firebaseConfig = { … } kopieren und hier einfügen.

Die heruntergeladene index.html auf GitHub hochladen und die alte Datei ersetzen. Danach funktioniert die App auf jedem Gerät.

Firebase ist nur in diesem Browser verbunden. Lade die fertige index.html herunter und ersetze sie auf GitHub.
